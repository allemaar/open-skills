# Activation primer

Status: **active**.

Use this paste-sized prompt when opening the other participant's new session. It accelerates orientation without replacing the canonical handshake, primer, or whole-inbox reconciliation.

```text
Load /agent-mailbox.
You are: <CALLSIGN>
Mailbox: <Handler-supplied root or inbox>
Peer waiting: <CALLSIGN>
Objective: <bounded objective>
Optional arrangement and role: <preset / role, or none>
Outstanding obligation: <message UUID or plain description>
You may: <authorized actions>
You may not: <prohibited actions>
First action: read the skill and primer, then reconcile the complete addressed inbox against durable dispositions before replying.
```

The receiving agent independently validates every coordinate. Do not paste credentials, private ledger contents, raw logs, or message bodies. If the room is established, use `resume → state`; do not restart the handshake.
