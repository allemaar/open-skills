# Diagnose an arrangement without building a configuration matrix

Status: **active**.

> Composition is diagnostic vocabulary. It helps identify what an arrangement forgot; it does not assemble a new mailbox state machine.

Named presets are what agents propose. Diagnose a failing or home-grown arrangement with three questions:

1. **Who holds the pen?** Name one current writer or coordinator for each shared artifact.
2. **How does challenge enter?** Counsel, independent verification, blind first pass, convergence break, or no deliberate challenge.
3. **Is continuity attached?** If work may pause, name the Working Agreement projection and acknowledged handoff state; otherwise leave continuity off.

Timing and recovery are not separate configuration dimensions. Timing normally follows the chosen preset. Each preset names the characteristic failure it creates and the recovery recipe to load.

Use the diagnosis to propose one small adjustment:

```text
Observed gap: <missing pen / challenge / continuity>
Proposed adjustment: <one active preset or operation>
Exit condition: <when the adjustment stops>
Authority unchanged: yes
```

Do not silently combine every available operation, invent a role hierarchy, or change ownership. A bespoke arrangement is allowed when the Handler directs it; record it in ordinary language and keep the same three checks.
