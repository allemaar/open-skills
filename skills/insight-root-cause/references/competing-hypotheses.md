# Competing causal hypotheses

Load only when multiple credible explanations remain. Owner: insight-root-cause, Challenge the links.

- Compare the plausible explanations against the same material observations. Allow interacting causes; do not manufacture rivals to fill a quota.
- For each observation, ask what each explanation would predict and whether it supports, contradicts or fails to distinguish them. Missing support is not contradiction; absent evidence counts against an explanation only when that evidence should have been observable.
- Identify the observation or bounded check that would best distinguish the remaining explanations. Check whether the conclusion changes if its decisive evidence is unreliable or withdrawn. Propose the check; do not run it.

Return the supported explanation or unresolved alternatives, the decisive evidence, and what would change the conclusion. A short comparison is enough; use a matrix only when it clarifies the differences. Do not turn inconsistency counts into probabilities or force a winner when the evidence cannot discriminate. Then finish the parent's Challenge the links checks before continuing to Report and test.
