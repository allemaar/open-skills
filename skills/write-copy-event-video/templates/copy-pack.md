# Event video copy pack

Use this as an output structure, not text to read aloud. Default workflow produces V1–V3 independently and V4 after cross-examination. Use the candidate content sections for each full variant and present V4's usable copy first. Put shared records and original variants after it or in clearly linked artifacts. Omit only genuinely inapplicable fields; unresolved release facts remain visible.

## Reader order

1. V4 recommended copy: spoken text, on-screen sequence and caption, with its voice handoff accessible.
2. Compact rationale, synthesis trace, remaining weakness and what would change the recommendation.
3. Original V1, V2 and V3, preserved verbatim and readily accessible.
4. Shared evidence, brief, workflow provenance and detailed review records.
