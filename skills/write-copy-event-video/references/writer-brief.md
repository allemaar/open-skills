# Independent writer brief

The coordinator supplies the same frozen common brief to three isolated writers. Each writer receives a different perspective and returns one complete variant. This reference is the leaf contract, not another orchestration workflow.

## Dispatch envelope

```text
WRITE-COPY-WRITER-RESOLVED
role: leaf-writer
depth: 1
variant: V1 | V2 | V3 (one assigned value)
perspective: [specific assigned lens]
deadline: [finite time]
repair-limit: 1 factual-or-format repair
mutation-scope: no shared edits; return text or assigned output only
subdelegation: forbidden
```

Include:

- Frozen brief/version: offering, occurrence, intended audience/stage, primary promise, one action and exact destination/access path.
- Verified fact ledger and sources, uncertainties, prerequisites and limits. Research summary including evidence boundaries; do not ask each writer to research independently.
- Locale, form of address, accepted and rejected approaches with reasons, requested energy and simplicity, duration and spoken-word budget.
- Reusable course versus occurrence fields, casting/model status, production continuity and spending constraints.
- Required output schema below; applicable environment instructions and their exact directive IDs when the host uses them.

Do not supply another writer's draft, a preferred winner, or review findings before all initial candidates return. Shared approved source facts and a shared CTA are not creative contamination. Use separate agents/contexts even when concurrency requires a queue. If the runtime cannot isolate contexts, disclose sequential drafting rather than call it independent.

## Leaf task

Write one complete event invitation from the assigned perspective. Follow the specialist's copy and voice rules. Do not invoke the specialist's dispatch, review, synthesis or completion hooks. Do not spawn workers, conduct new research, generate media, spend credits, publish, or alter another candidate. Unknowns stay unknown. If the assigned lens requires an unsupported claim, adapt the lens and state why.

Use short native sentences, familiar words, one idea per sentence/beat, and a concrete reason to attend. Intrigue needs a real payoff. Preserve the audience's dignity and intended register. Keep one primary action, the common duration budget and exact event facts.

## Return schema for each of V1–V3

1. Variant ID, perspective, one-sentence rationale and brief version used.
2. Complete clean spoken master plus optional separate occurrence insert.
3. Complete ordered on-screen text and minimal post caption.
4. Beat sheet: ID, purpose, spoken line, overlay, intended visual meaning, pause/reading time, estimated duration, CTA role and source IDs.
5. Word count, assumed rate, pause/hold budget and estimated total; no unmeasured timing guarantee.
6. Full **Full spoken script | Delivery** table covering all lines in order: regular baseline, sparse exact emphasis spans and intent, optional pause locations/estimated lengths, continuous flow and return to baseline. Separate pronunciation map and model-aware input text; no bold or production notes in payload. Flag unsupported local-emphasis controls. Plain text for unknown model; no audio generated. Label planned casting excerpts as excerpts; full-script delivery remains untested.
7. Claim uncertainties, likely weakness, intentional repetition and any production needs.

This is one full copy, not three alternative hooks. Return and stop. The coordinator retains the original, checks facts, invokes the review engine, and writes V4 after its recommendation.
