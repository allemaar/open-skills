# Teach a topic

Teach one useful next capability from the learner's purpose and demonstrated understanding. A direct question can receive a direct answer; it does not automatically start a curriculum, pre-test or persistent profile.

## Establish the next step

Reuse the goal, constraints, available time and supplied material. Ask a light starting question or offer a small diagnostic only when their level changes the next lesson. Use relevant authorized prior evidence when accessible; missing history is unknown progress, never an invented earlier lesson.

Choose an achievable outcome the learner can explain, distinguish or perform. Teach blocking prerequisites or narrow the session within that goal. Change the overarching mission only at the learner's direction.

Use relevant trusted resources. Check changing or specialized claims with appropriate available sources within a bounded lookup; name unavailable or unverified evidence. No research fleet, paid materials, external signup or community membership is required. High-stakes topics retain actual safety, professional and action-authorization constraints.

## Explain, practice and respond

Teach only what serves the next capability. Explain the concept with a worked example or contrast, introducing prerequisites before relying on them. Label illustrative assumptions.

Offer a suitable recall or application task with observable criteria, respecting explanation-only requests. Vary inputs when testing transfer rather than repeating the same answer and calling it understanding. Respond to the actual attempt: explain correct reasoning, misconceptions and a useful hint or correction. Do not invent errors, attempts or improvement.

Keep evidence distinct:
- Exposure means material was presented.
- Immediate fluency concerns performance while the example or scaffolding is available.
- Observed performance states what this learner actually did and what help they needed.
- Retention needs a later check after a delay.

One correct exercise proves only that attempt under its conditions. It establishes neither broad mastery nor retention. Avoid word-count tricks and unsupported mastery labels. Offer a later review or transfer task when useful; suggestions create no schedule.

## Optional progress and export

Conversation output is sufficient. Capture progress only when selected, reusing the authorized destination and conventions. Resolve missing destination/scope without requesting permission already supplied.

Record the learner-directed goal, actual demonstrated evidence and assistance, unresolved uncertainty and useful next practice. Omit unnecessary sensitive details. Inspect target/auxiliary leaves and every ancestor without following redirects; refuse unsafe paths. Read current content, retain recovery material and use supported revision protection or a verified single-writer arrangement. Preserve user and concurrent edits.

Unsupported ownership/concurrency or a conflicting revision blocks the write, not useful proposed progress text. Keep current state coherent and history under its existing owner. Do not erase past observations to conceal a setback. On write failure, stop and report completed, failed and unstarted updates; never claim unsaved progress persisted.

Markdown is sufficient. An HTML/export artifact is optional when requested. State bundled versus linked assets and test the intended opening/offline behavior when possible. Linked assets are not self-contained. Report untested or unavailable export capability; return usable text instead of pretending success.

## Return or stop

Stop when the learner stops, the session outcome is met, the agreed bound is reached or resources are insufficient. Return what was covered, actual performance evidence, uncertainty and one useful next practice/review. State save/export status exactly. No publication, reminder, external enrollment or subagent is required or automatically launched.
