# Create

Load for a new skill. Read [authoring](authoring.md).

1. Establish the task and representative success and failure. Check the selected inventory for an existing owner. Enrich that owner when appropriate; don't invent a new skill merely to satisfy a proposed name.
2. Apply the [authoring clarification procedure](authoring.md#clarify-intended-behavior) to unresolved behavior choices, then choose the smallest sufficient structure. When the job needs a type-specific operating or lifecycle contract, use the [recipe selector](recipes.md); otherwise keep the generic path. Draft the entrypoint and only the references, templates or scripts the task needs. Keep unavailable evidence explicit.
3. For an authorized write, use [write](write.md) before drafting to disk or replacing source. Stage outside discovery when the destination is actively loaded; otherwise draft at the authorized source path. In a managed library, follow its manager's naming, metadata and local activation procedure; in an ordinary repository use its source-write conventions without inventing a manager. Evaluate with [evaluate](evaluate.md), close required routes and inspect the final diff before activation.

Return the complete draft, selected structure, validation evidence and unchecked behavior. Creation does not authorize installation, commits or outward publication.
