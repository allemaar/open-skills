# Hybrid [need:hybrid]

Spine: one shared bottom line; separate modules retaining each represented
need's spine; `· · ·` between modules; one shared action row for the entire
output.

After loading this file, identify every need represented by a module. Before
composing that module, load its direct file from this `needs/` directory
completely and confirm its terminal marker. Load only represented needs. Do not
replace their spines with a generic module shape or give each module its own
bottom line or action row.
