# Timeline [need:timeline]

Spine: events whose order changes meaning; pivotal turn; current consequence.
Use Investigate instead while cause remains open.

Example:

**The agreement failed when temporary use became routine:**

- **March:** temporary shared-space use begins.
- **May:** both parties agree verbally to alternate weeks.
- **June:** visitors use the space during the other party's weeks. This is the
  pivotal turn.
- **Now:** the written schedule remains unsigned, so it is unenforceable.
