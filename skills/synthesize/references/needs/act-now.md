# Act now [need:act-now]

Spine: actions in order; trigger and done-signal for each; actor; recourse.
Keep one contiguous action zone. Mark one-way steps plainly.

Example:

**Burst pipe, in order:**

1. Close the sink valve clockwise. Done when water slows to a drip.
2. Still flowing? Close the main valve. Done when all taps stop.
3. Photograph the damage before cleanup. The insurer needs the original state.
4. Call the plumber and say: "burst supply line; valve closed."
