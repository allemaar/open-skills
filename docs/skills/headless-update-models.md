# headless-update-models

[All skill guides](../README.md) · [Catalog](../../SKILLS.md)

Refresh canonical headless model evidence and consumer projections.

**Family:** Orchestration & dispatch. **Subagents:** No subagent step prescribed.

## When to use it

- Update family model guidance
- Refresh stale provider evidence

## When not to use it

- Live quota checks or benchmark inference

## How to use it

Install this skill in a supported runtime, then give it the relevant material and a concrete request. For example:

```text
/headless-update-models refresh the provider model guidance
```

## Flow

1. Identify the canonical source and exact write cohort, including established copied or plugin installations.
2. Gather current primary model, pricing and benchmark evidence without benchmark inference.
3. Update dated records, project them to registered headless consumers, and refresh the selected established installations through verified installers while retaining preimages.
4. The explicit update request authorizes that scope; new installations require a separate request.
5. Verify source and installed parity and report gaps.
6. When refreshing an existing installation, derive and stage only its verified established cohort; never add a member implicitly.
7. Projection counts derive from the owner’s current asset and consumer arrays.

## Subagents

The skill defines no subagent step; host rules still apply.

This describes the skill's own workflow. Available tools and the runtime's permission rules still apply.

## What you get

Updated guidance and a dated coverage and parity report.
