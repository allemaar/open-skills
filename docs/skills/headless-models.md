# headless-models

[All skill guides](../README.md) · [Catalog](../../SKILLS.md)

Select a headless model using capability, cost and availability evidence.

**Family:** Orchestration & dispatch. **Subagents:** No subagent step prescribed.

## When to use it

- Compare providers for a task
- Choose a model and effort

## When not to use it

- Refreshing the catalog itself

## How to use it

Install this skill in a supported runtime, then give it the relevant material and a concrete request. For example:

```text
/headless-models recommend a model for a bounded code review
```

## Flow

1. Define output needs and constraints
2. Check current provider evidence and local availability separately
3. Compare suitable choices and disclose cost uncertainty
4. Recommend a supported route without changing the caller's selection
5. Preserve dated login ordering and use live discovery for current access; no historical observation proves present entitlement.

## Subagents

The skill defines no subagent step; host rules still apply.

This describes the skill's own workflow. Available tools and the runtime's permission rules still apply.

## What you get

A sourced model and effort recommendation.
