# write-copy

[All skill guides](../README.md) · [Catalog](../../SKILLS.md)

You need promotional copy and want the writing to match the subject, audience and medium. This entry point routes event campaign videos to their specialist and makes gaps in other specializations explicit.

Event campaign videos have a specialist workflow. For topics without an implemented specialization, an ordinary scoped draft can be offered without claiming a tested family recipe.

## Where it fits

Use write-copy-event-video directly for a known event video; use human-rewrite for faithful prose repair.

**Family:** Write copy. **Subagents:** No subagent step prescribed.

## When to use it

- Request campaign copy
- Find the right event-copy workflow

## When not to use it

- Faithful repair of existing prose

## How to use it

Start with a concrete request. For example:

```text
/write-copy Draft a campaign-video brief for a two-hour community workshop aimed at first-time attendees. Use the supplied verified event details and invite registration.
```

**Required skills:** [write-copy-event-video](write-copy-event-video.md). Install these first.

## Flow

1. Identify the subject and intended audience
2. Select an available specialization matching the request
3. Pass the brief and preserve its constraints
4. Report a routing gap when no suitable specialization exists

## Common questions

**Does drafting copy start media production or publication?**

No. Copy, media generation and publishing are separate actions.

**Is every event request an event-video campaign?**

No. An event is a subject and video is a medium. The route depends on what the requested copy is for.

## It is working when

- The route matches the requested topic and medium or states the specialization gap.
- The draft preserves the intended audience and language and leaves unknown claims visible.
