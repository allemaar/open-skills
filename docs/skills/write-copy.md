# write-copy

[All skill guides](../README.md) · [Catalog](../../SKILLS.md)

Route promotional copy requests to the appropriate specialization.

**Family:** Write copy. **Subagents:** No subagent step prescribed.

## When to use it

- Request campaign copy
- Find the right event-copy workflow

## When not to use it

- Faithful repair of existing prose

## How to use it

Install this skill in a supported runtime, then give it the relevant material and a concrete request. For example:

```text
/write-copy draft campaign copy for this event
```

**Required skills:** [write-copy-event-video](write-copy-event-video.md). Install these first.

## Flow

1. Identify the subject and intended audience
2. Select an available specialization matching the request
3. Pass the brief and preserve its constraints
4. Report a routing gap when no suitable specialization exists

## Subagents

The skill defines no subagent step; host rules still apply.

This describes the skill's own workflow. Available tools and the runtime's permission rules still apply.

## What you get

A routed copy request or a stated capability gap.
