# reflect

[All skill guides](../README.md) · [Catalog](../../SKILLS.md)

The work is moving, but you want a short pause before continuing. Reflect names what has been assumed, where confidence is weakest and what a fresh start would change, without requiring a document or formal review.

The reflection requires no artifact and enforces no stop or approval. A concern it reveals may warrant a separate check, but the reflection itself does not establish a verification verdict.

## Where it fits

Use reflect for freeform reconsideration, verify for a formal gate, and ask-gate for deciding whether a question belongs with the user.

**Family:** Planning & execution. **Subagents:** No subagent step prescribed.

## When to use it

- You want to step back.
- You want to reconsider the current approach.

## When not to use it

- You need a formal verification verdict.

## How to use it

Start with a concrete request. For example:

```text
/reflect Step back from our current migration approach: identify unstated assumptions, the weakest confidence and what you would change starting fresh.
```

## Flow

1. Name unstated assumptions.
2. Explain where confidence is lowest and why.
3. State what you would do differently starting fresh.

## Common questions

**Does reflection approve the work to continue?**

No. It surfaces concerns without deciding a gate or enforcing a next action.

## It is working when

- The response names assumptions, the least certain area and what would change on a fresh start.
- It does not present the pause as evidence of formal verification.
