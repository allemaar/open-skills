# reflect

[All skill guides](../README.md) · [Catalog](../../SKILLS.md)

Pauses to expose assumptions and uncertainty without a gate.

**Family:** Planning & execution. **Subagents:** No subagent step prescribed.

## When to use it

- You want to step back.
- You want to reconsider the current approach.

## When not to use it

- You need a formal verification verdict.

## How to use it

Install this skill in a supported runtime, then give it the relevant material and a concrete request. For example:

```text
/reflect Reflect on our current approach.
```

## Flow

1. Name unstated assumptions.
2. Explain where confidence is lowest and why.
3. State what you would do differently starting fresh.

## Subagents

This is an inline pause with no prescribed delegation.

This describes the skill's own workflow. Available tools and the runtime's permission rules still apply.

## What you get

A candid reflection, not a formal verdict.
