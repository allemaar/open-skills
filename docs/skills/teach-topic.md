# teach-topic

[All skill guides](../README.md) · [Catalog](../../SKILLS.md)

You want to learn a capability through explanation and practice, not just receive an answer. The lesson starts with your goal and selects one achievable next step, then gives feedback on what you actually do.

A worked example and suitable practice lead to feedback on the actual attempt. Exposure, assisted performance and later retention are different kinds of evidence.

## Where it fits

Use this for guided learning and practice; a direct one-off explanation can remain a direct answer.

**Family:** Human output. **Subagents:** No subagent step prescribed.

## When to use it

- A learner wants guided practice or continued learning toward a stated goal.
- An observed attempt needs feedback and a suitable next exercise.

## When not to use it

- A direct one-off explanation already meets the request; no curriculum is required.
- You need certification, action authorization or a claim of mastery without demonstrated evidence.

## How to use it

Start with a concrete request. For example:

```text
/teach-topic Help me compare travel times from this timetable. Give me one application exercise and feedback, and do not create progress files.
```

## Flow

1. Reuse the learner's goal and accessible evidence; check starting knowledge only when it affects the next lesson.
2. Choose one achievable capability and explain it with an example or contrast.
3. Observe recall/application, give specific feedback and distinguish assistance, performance and unmeasured retention.
4. Return useful review or stop; save or export only when selected and safely supported.

## Common questions

**Does one correct answer establish mastery?**

No. It establishes performance on that attempt under its conditions, not broad mastery or retention.

**Will the skill save my progress automatically?**

No. Conversation is sufficient. A selected save uses the authorized destination and records actual evidence and assistance, not invented mastery.

## It is working when

- Feedback refers to the learner’s actual response and the assistance given.
- The result states what was covered, remaining uncertainty and a useful next practice; any save status is accurate.

## Subagents

No subagent step is prescribed; teaching and source checks remain bounded in the current session.

This describes the skill's own workflow. Available tools and the runtime's permission rules still apply.

## What you get

An explanation/practice/feedback progression with actual learning evidence and next review; optional safely saved progress or a clearly limited export.
