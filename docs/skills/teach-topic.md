# teach-topic

[All skill guides](../README.md) · [Catalog](../../SKILLS.md)

Teaches one useful next capability with practice, evidence-based feedback and optional progress capture.

**Family:** Human output. **Subagents:** No subagent step prescribed.

## When to use it

- A learner wants guided practice or continued learning toward a stated goal.
- An observed attempt needs feedback and a suitable next exercise.

## When not to use it

- A direct one-off explanation already meets the request; no curriculum is required.
- You need certification, action authorization or a claim of mastery without demonstrated evidence.

## How to use it

Install this skill in a supported runtime, then give it the relevant material and a concrete request. For example:

```text
/teach-topic Help me compare two travel times from this timetable. Check only the prerequisites that matter, give me an application task and do not create progress files.
```

## Flow

1. Reuse the learner's goal and accessible evidence; check starting knowledge only when it affects the next lesson.
2. Choose one achievable capability and explain it with an example or contrast.
3. Observe recall/application, give specific feedback and distinguish assistance, performance and unmeasured retention.
4. Return useful review or stop; save or export only when selected and safely supported.

## Subagents

No subagent step is prescribed; teaching and source checks remain bounded in the current session.

This describes the skill's own workflow. Available tools and the runtime's permission rules still apply.

## What you get

An explanation/practice/feedback progression with actual learning evidence and next review; optional safely saved progress or a clearly limited export.
