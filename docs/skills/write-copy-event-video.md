# write-copy-event-video

[All skill guides](../README.md) · [Catalog](../../SKILLS.md)

You need an event invitation that makes a credible promise and gives viewers one useful next step. The skill freezes the audience, programme facts, occurrence details, destination and timing in a common brief, then develops distinct complete scripts against that same evidence.

Present the fourth version first and preserve the three originals. Separate evergreen narration from occurrence details, overlays and voice directions. Duration is an estimate until auditioned; an unknown voice model receives plain text, and the copy workflow does not generate audio or publish.

## Where it fits

Use this event-video specialization for a draft copy and voice handoff. Media production, voice audition, scheduling and publication require separate work.

**Family:** Write copy. **Subagents:** Conditional.

## When to use it

- Draft a promotional event video
- Develop a voiceover handoff

## When not to use it

- Generating media or publishing

## How to use it

Start with a concrete request. For example:

```text
/write-copy-event-video Draft an invitation for the supplied workshop programme and event page, aimed at beginners, with one registration action and a 30-second target.
```

**Required skills:** [insight-cross-examine](insight-cross-examine.md), [insight-angles](insight-angles.md), [insight-critique](insight-critique.md), [insight-assess](insight-assess.md), [insight-explore](insight-explore.md), [human-output](human-output.md). Install these first.

## Flow

1. Establish the brief and verify event facts
2. Commission three independent perspectives when available
3. Prepare each complete draft variant with its full spoken-script/delivery table and labelled voice input, keeping production settings separate.
4. Check facts and cross-examine the complete variants.
5. Synthesize V4 with the same complete script, delivery and voice-input schema; present it first.
6. Keep actual voice-provider configuration and production records in a separate operational handoff; the copy pack carries intent, status and locators.

## Common questions

**What if isolated writers or a required review dependency are unavailable?**

Label sequential drafting as less independent, and identify a missing review as unperformed. Do not imitate the missing dependency or claim independent agents ran.

**Can an old event script be reused by changing only the date?**

Revalidate the programme, audience, occurrence details, availability and destination, then review affected narration, overlays, caption and timing.

## It is working when

- The copy pack keeps supported claims, source dates, one primary action, original variants and the synthesis trace visible.
- Each full variant has a complete delivery plan and separate clean voice input, with unmeasured timing and production gaps labeled.

## Subagents

Use three isolated writer subagents when available; label a sequential fallback and its reduced independence. If a required review dependency is missing, report the incomplete review rather than imitate it.

This describes the skill's own workflow. Available tools and the runtime's permission rules still apply.

## What you get

A draft copy pack with variants, synthesis and open decisions.
