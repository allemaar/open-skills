# Co-write a document

Use this recipe for authoring new material together. Faithful repair of one existing text and a single feedback revision are narrower jobs. Here the writer and collaborator develop the document while preserving its source limits and the writer's intervening edits.

## Prerequisites and selected install set

Selected skill install set: **none**. Read this recipe directly; supply the intended document and any source material or existing draft. No account, external service, parser or subagent is required or prescribed. A capable text collaborator is sufficient; safe file access is needed only when saving is authorized. If sources are unavailable, name the uncovered material and return useful partial work without implying it was read.

Optional neighboring guides: [human-rewrite](../skills/human-rewrite.md) for faithful repair of one existing text, and [synthesize](../skills/synthesize.md) for a single intent-based feedback revision. These skills are not part of this recipe's install set and are never invoked automatically.

## Establish the work

Reuse the audience, purpose, requested opening/structure and current material. Read the supplied source fully within its actual scope; identify inaccessible material instead of pretending it was reviewed. Agree only missing consequential choices: reader prerequisites, source limits, destination and useful collaboration cadence.

Use conceptual beats for the argument's next move, blocks for incremental wording. Respect requested cadence and structure; force no alternate openings.

Optional raw-fragment capture is an early branch, not required preparation. If requested, capture fragments without polishing away uncertainty or quotation boundaries. Preserve who supplied each fragment and its source when known; label paraphrases and unknown origin. Keep capture distinct from the shaped output. Save fragments only to their authorized destination and return to shaping when the writer is ready.

## Make one useful move

Keep raw source read-only. Shape a separate document. Before each move, read the current output and the relevant source; do not rely on a stale remembered draft.

When direction is open, offer different next moves and their purpose, such as mechanism versus consequence. Draft an already-chosen move directly.

Introduce concepts before relying on them. Preserve exact quotations, numbers, attribution and uncertainty from evidence. New connective prose is authorship; it does not authorize fabricated facts. If a needed example is missing, mark the gap or ask for it when necessary. A hypothetical example must be explicitly selected and labeled, never presented as a real incident or quotation.

Present the selected beat or block with enough adjoining context to assess it. Carry accepted material forward; keep rejected options out of the current draft. Cosmetic corrections need no new approval unless requested.

## Save without losing work

Use the existing authorized output. Before every write, inspect its leaf/ancestor chain without following links, refuse redirects, and reread live content. Retain recoverable preimages. Use supported revision protection or a verified single-writer arrangement for overlapping work.

Merge only the agreed block into the current document. Preserve intervening edits, including changes to preceding paragraphs. If edits overlap or expected revision changed, show the collision and preserve the proposed block rather than replacing stale whole-file content. Stop on a failed write and report exact save status. Do not modify raw material to conceal a gap.

At completion or user stop, return the useful document or its exact saved location, the current direction and remaining gaps. Stop means no further questions or implicit publication. Save only already-authorized accepted material; silence does not approve a new block.

## Worked move

Current argument: a repair service explains why appointment reminders fail. The writer asks to show the consequence next. Draft: “When a reminder goes to an abandoned address, the customer may miss the visit.” If the sources contain no real example, retain this as a labeled illustration only with the writer's agreement; do not invent a customer quote.

## Reusable prompt

“Co-write this document for the named audience and purpose. Follow my structure and use beats or blocks as requested. Keep the source read-only, ground claims, preserve my edits between turns, and return useful partial work if I stop. Publish nothing.”

## Expected output and non-use

Expect agreed text or an exact saved location, proposed material clearly distinguished where necessary, factual gaps and unfinished sections. If a write fails, preserve the proposed block and recovery evidence and report saved-versus-unsaved status; do not continue writing. When checking a changed procedure, walk through an intervening paragraph edit and a missing-source claim; neither a source walkthrough nor a successful save proves the document's claims. This recipe is unnecessary for a one-shot answer or already-selected rewrite. It creates no journal, schedule or cleanup task.
